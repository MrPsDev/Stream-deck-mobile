# Stream Deck Mobile

Use your Android phone as a custom Stream Deck for your Windows PC.

## Download

Go to the **Releases** page and download:

- **Android APK** for the phone app
- **Windows ZIP** for the PC app

## How To Use

1. Download and extract the Windows ZIP.
2. Open `Stream Deck PC.exe`.
3. Install the APK on your Android phone.
4. Open the mobile app.
5. Scan the QR code shown in the PC app.
6. Create buttons and control OBS, hotkeys, media, volume, URLs, and system commands.

## OBS Setup

For OBS buttons to work:

1. Open OBS.
2. Go to `Tools > WebSocket Server Settings`.
3. Enable WebSocket Server.
4. Make sure the OBS port and password match the PC app settings.

Usually:
- Host: `localhost`
- Port: `4455`
